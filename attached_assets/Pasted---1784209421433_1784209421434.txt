ШЕШЕНДІК СӨЗДЕР

==================================================

Әр би-шешеннің барлық шешендік сөздері толық мәтінімен енгізілсін.

Қысқартылмасын.

JSON файлында сақталсын.

Әр шешендік сөз жеке объект ретінде құрылсын.

Құрылымы:

id

title

category

period

description

fullText

keywords

source

relatedPersons

relatedEvents

Әр шешендік сөз карточка ретінде көрсетілсін.

Карточка ішінде:

✔ Шешендік сөздің атауы

✔ Қысқаша түсіндірме

✔ Түрі

✔ Айтылған кезеңі

✔ Ұзақтығы

✔ Оқу уақыты

✔ "Толық оқу"

батырмасы орналассын.

Толық оқу батырмасын басқанда Modal немесе жаңа бет ашылсын.

Жаңа бетте:

--------------------------------------------------

Шешендік сөздің толық мәтіні

--------------------------------------------------

Ешқандай қысқартусыз толық көрсетілсін.

Абзацтарға бөлінсін.

Қазақ қарпі дұрыс сақталсын.

Үлкен әрі оқуға ыңғайлы қаріп қолданылсын.

Dark Mode қолдасын.

--------------------------------------------------
