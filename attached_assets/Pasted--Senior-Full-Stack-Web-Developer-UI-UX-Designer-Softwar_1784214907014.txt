Сен әлемдік деңгейдегі Senior Full Stack Web Developer, UI/UX Designer, Software Architect және Digital Library System Engineerсің.

Қазіргі жобаны толық сақта.

Бұрын жасалған барлық кодтың ешбір бөлігін өзгертпе.

"Ақындар", "Жазушылар", "Жыраулар", "Би-шешендер", "Ағартушылар" модульлері толық жұмысын жалғастырсын.

Тек барлық авторларға ортақ Universal Author Page модулін жаса.

Бұл модуль барлық тұлғалар үшін қолданылсын:

• Ақындар

• Жазушылар

• Жыраулар

• Би-шешендер

• Ағартушылар

Барлық бөлімдер бірдей дизайн қолдансын.

Жеке беттің компоненттері ортақ болсын.
