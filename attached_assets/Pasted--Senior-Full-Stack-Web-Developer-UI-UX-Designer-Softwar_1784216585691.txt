Сен әлемдік деңгейдегі Senior Full Stack Web Developer, UI/UX Designer, Software Architect және Digital Library System Engineerсің.

Қазіргі жобаны толық сақта.

Бұрын жасалған барлық кодтың ешбір бөлігін өзгертпе.

"Ақындар", "Жазушылар", "Жыраулар", "Би-шешендер", "Ағартушылар", "Universal Author Page" және "Шығармалар кітапханасы" модульлері толық жұмысын жалғастырсын.

Тек жаңа "Professional PDF Reader" модулін қос.

Жоба архитектурасын өзгертпе.

Ортақ компоненттерді қайта пайдалан:

• PDFViewer

• SearchBar

• BookmarkPanel

• ReadingProgress

• NotesPanel

• HighlightToolbar

• Breadcrumb

• Sidebar

• DownloadButton

• PrintButton

• FavoriteButton

React 19 + TypeScript + Tailwind CSS қолдан.

Framer Motion қолдан.

React Router қолдан.

Lucide React Icons қолдан.

PDF көрсету үшін pdf.js (Mozilla PDF.js) кітапханасын пайдалан.

Backend қолданылмасын.

OpenAI API қолданылмасын.

Жоба толық Offline режимінде жұмыс істесін.

Барлық PDF файлдары:

public/pdf

папкасында сақталсын.
