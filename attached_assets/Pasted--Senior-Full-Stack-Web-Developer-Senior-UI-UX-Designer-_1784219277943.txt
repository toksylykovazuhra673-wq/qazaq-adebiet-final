Сен әлемдік деңгейдегі Senior Full Stack Web Developer, Senior UI/UX Designer, Software Architect, NLP Engineer және Digital Literature Analysis System Engineerсің.

Қазіргі жобаны толық сақта.

Бұрын жасалған барлық кодтың ешбір бөлігін өзгертпе.

"Ақындар", "Жазушылар", "Жыраулар", "Би-шешендер", "Ағартушылар", "Universal Author Page", "Шығармалар кітапханасы", "PDF оқу жүйесі" және "Digital Reading System" модульлері толық жұмысын жалғастырсын.

Тек жаңа "Автоматты әдеби талдау" модулін қос.

Жоба архитектурасын өзгертпе.

TypeScript

Tailwind CSS

Framer Motion

React Router

Lucide React Icons қолдан.

Интернет қолданылмасын.
